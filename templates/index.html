🌐 Federated Learning Workflow

The deployed AI model was collaboratively trained using the Federated Averaging (FedAvg) algorithm across three independent agricultural datasets from Oyo, Kaduna, and Benue. During training, only model parameters were shared, preserving data privacy while producing a highly accurate global model.

Why Federated Learning?
Instead of combining all plant images into one central database, each participating region trained a local model independently. Only the learned model parameters were shared and combined using the FedAvg algorithm, preserving data privacy while producing a highly accurate global model.
